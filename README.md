# 模試成績管理 — 個人成績表作成アプリ

Excelの模試成績総覧を読み込み、氏名を中心に同一生徒を照合し、5教科と総合の偏差値推移を表示してA4横向きで一括印刷する、ブラウザだけで動くアプリです。

## 使い方

1. `index.html` を Chrome または Edge で開きます。Webサーバーは不要です。
2. 「模試データを取り込む」から `.xlsx` ファイルを選択（複数可）します。
3. 模試名、実施日、学年、氏名と6偏差値の割当を確認して「内容を確認して登録」を押します。
4. 生徒一覧から印刷する生徒をチェック（全員も選択可）して「成績表を作成」へ進みます。
5. A4横のプレビューを確認して「PDF保存・印刷へ進む」を押します。印刷ダイアログで「PDFに保存」を選択すると、選択した生徒全員の成績表が **1つのPDF** になります。
6. 設定画面で必ず定期的にバックアップ（JSON）をダウンロードします。

## 主な機能

- Excel見出しの自動解析：上段の「国語・数学・英語・理科・社会・総合」と下段の「偏差値」を組み合わせて列を識別。列の手動修正も可能
- 各模試の実施日・学年を見出しから推定、登録前の確認・編集
- 同一年度・異なる回の成績を氏名＋学年で照合（全角半角・空白は正規化）
- 同じ模試名・実施日・学年の重複登録を防止
- 生徒検索、学年絞り込み、総合偏差値順ソート
- 教科別5本と総合1本の推移グラフ（左60%：右40%）
- 全期間の偏差値表、任意の講師コメント
- 1名1ページ、A4横、選択者をまとめた印刷／PDF保存
- ローカル保存、バックアップと復元、模試削除

## データとプライバシー

ファイルの解析と描画はブラウザ内だけで実行されます。外部APIや外部CDN、分析ツールを使用しません。会員番号・通学校などの不要な項目は保存しません。GitHubリポジトリに成績表やExcelは含めません。

登録データはブラウザの `localStorage` に保存されます。ブラウザデータの削除や別ブラウザへの移行で失われるため、**バックアップ取得は必須**です。同じファイルを `file://` で開く場合、ブラウザやファイルの場所によって保存領域の取り扱いが異なることがあります。同じURLで継続利用してください。

> GitHub Pagesで公開すると、Webアプリのコード自体は一般公開され得ますが、利用者が登録したExcel・成績データは自動でGitHubにアップロードされません。共同PCでは閲覧者に十分注意してください。

## 注意点

- ブラウザ標準の印刷機能を利用します。Chrome/Edgeで印刷方向を「横」、用紙を「A4」、余白を「なし」または「デフォルト」にしてください。成績表のページ割り付けは `@page` で指定しています。
- XLSXのZIP圧縮解凍には `DecompressionStream('deflate-raw')` を使うため、対応する新しいChrome/Edgeが必要です。マクロ付き `.xlsm` や古い `.xls` には対応しません。
- 異なる模試母集団の偏差値は厳密に直接比較できないことがあります。
- 大量の模試（例：20回以上）ではA4 1枚に全回分の数値表を載せると文字が小さくなります。長期運用では折り返しや表示様式の調整が必要です。
- 氏名・学年の一致により照合します。同名同学年の生徒を完全に区別するID管理は今後の拡張事項です。同姓同名があり得る実運用では必ず登録前に照合結果を確認してください。

## 複数Excelの一括登録

1. 「模試データ」から「Excelファイルを取り込む」を選択します。
2. CtrlキーやShiftキーで複数の `.xlsx` ファイルを同時に選択します。
3. すべてのファイルの自動判定結果（模試名・実施日・人数・列の対応）を一覧で確認します。
4. 必要なファイルだけ「詳細」で列や日付を修正します。登録しないファイルはチェックを外します。
5. 「選択したファイルを一括登録」を押すと、重複や不明な照合を検証したうえでまとめて保存します。問題がある場合はまとめて登録を中止します。

Excelや生徒データをGitHubにアップロードする必要はありません。

## 年度・学年別管理・保存済み成績表（追加機能）
- 画面上部の「年度」と「学年」を選ぶと、そのグループの生徒・模試のみ表示します。別学年へ移動しても既存データは残ります。
- Excel登録時の模試実施日と学年が選択中のグループと異なる場合、誤登録防止のため登録前に停止します。
- 以前の `mock-exam-report-v1` データは最初の起動で年度・学年別へコピーして移行します。元のv1データは削除しません。
- 成績表作成画面にある「個別成績表をアプリ内に保存」で、各生徒の成績表の印刷時点のHTMLをIndexedDBへ保存します。一括印刷操作時にも同時に保存します。
- サイドバーの「保存済み成績表」で閲覧・再印刷・削除できます。元の模試を追加・削除しても保存済みの数値は変わりません。
- PDF保存時は、用紙・年度・学年・氏名または人数・作成日時を含むファイル名を`document.title`に設定します。ブラウザの印刷ダイアログでのファイル名はブラウザやOSの仕様によって手動調整が必要な場合があります。
- バックアップ（JSON）は全年度・学年と成績表の保存履歴をまとめて取得します。ブラウザを変えた場合はバックアップから復元してください。

## PWA
- GitHub PagesのHTTPSサイトをChrome/Edgeで開き、ブラウザの「アプリをインストール」から追加できます。
- 濃紺背景・白い棒グラフの192px/512pxアイコンを使用しています。
- Service Workerはアプリのコードとアイコンだけをキャッシュし、生徒情報やExcelをキャッシュしません。オフライン起動に対応します。
- アプリの更新後はブラウザを再読み込みしてください。ブラウザの保存データを削除すると成績や保存済み成績表を失います。

## 学年混在ファイルの自動振り分け

年度・学年タブを事前に切り替える必要はありません。Excelを複数選択すると、各ファイルの実施日から年度（4月始まり）を、Excelの見出しから中1・中2・中3を判別します。一括確認画面の「自動登録先」で振り分け先を確認でき、選択したファイルはそれぞれの年度・学年にまとめて保存されます。登録後の表示学年は自動で切り替えず、上部の年度・学年選択から閲覧できます。学年を判別できないファイルは登録を止め、詳細欄で修正を求めます。既存の学年別データは保持されます。

## 保存済み成績表セット（フォルダ管理）
- 成績表作成画面の「成績表セットをアプリ内に保存」で、選択した生徒全員分を**1つのセット**として保存します。
- 「PDF保存・印刷へ進む」から一括印刷した場合も、その時点の成績表セットが自動で保存されます。
- 「保存済み成績表」画面には、セット名・作成日時・人数が表示されます。
- セットを開くと、**生徒1人の閲覧／個別印刷、チェックした生徒だけの複数印刷、全員一括印刷**が可能です。
- 保存済み成績表の数値・コメントは作成時点で固定されます。後から模試を追加しても更新されません。
- 以前の個別保存形式も保持し、同時刻に保存されたものは互換表示で1つのセットとしてまとめます。データの破棄・再登録は不要です。
- セットを削除すると、そのセット内の保存済み成績表も削除されます。元のExcelから読み込んだ模試データは削除されません。
- バックアップと復元は、古い個別保存形式と新しいセット形式の両方に対応します。

## 画面ごとに独立した年度・学年選択

- 「生徒一覧」には「生徒一覧の年度・学年」の専用ドロップダウンを追加しました。登録されている年度と各学年（中1～中3）を選択できます。
- 「生徒一覧」と「成績表作成」は同じ年度・学年選択を共有します。
- 「保存済み成績表」は独立した年度・学年選択を保持します。保存済み成績表で中1を選んでも、生徒一覧で選んでいた中2は変わりません。
- 画面を移動すると、その画面で最後に使った年度・学年を復元します。
- この切り替えは表示対象のみを変更し、登録済みの模試・成績や保存済みセットを削除しません。

## 印刷と保存は別操作

- 「PDF出力・印刷（アプリ内には保存しない）」は印刷ダイアログを開くだけで、保存済み成績表セットへ追加しません。
- 「成績表セットをアプリ内に保存」を押した場合だけ、新しい保存済みセットを作成します。印刷ダイアログは開きません。
- すでに保存済みのセットは、この仕様変更では削除されません。

## 前の画面に戻る

- 画面遷移の履歴がある場合、見出し左側に「← 戻る」を表示します。履歴がない初期状態では非表示です。
- 生徒一覧 → 個人成績 → 成績表作成など、直前の画面へ一つずつ戻れます。履歴は最大20件で、アプリを閉じるとリセットされます。
- 保存済み成績表の「セット一覧 → セット内生徒一覧 → 個人成績表」も戻れます。
- 年度・学年の表示状態と、生徒の検索・選択状態を可能な限り復元します。模試登録、成績表保存、削除などのデータ操作を取り消す機能ではありません。
- Excelの読み込み途中で戻る際には、未登録の内容を破棄するか確認します。PDFの印刷中は印刷ダイアログ側で操作してください。
